# Requirements: NotesBot

**Defined:** 2026-10-28
**Core Value:** Быстро сохранить текст в Telegram и позже найти его без потери
данных и доступа к чужим заметкам.

Источник — [существующие требования MVP](../docs/mvp.md). Новые возможности
при переносе не добавлялись. Список подтверждён пользователем 28 октября 2026 года;
идентификаторы нужны для связи требований с будущими фазами GSD.

## v1 Requirements

### Сохранение и чтение

- [ ] **NOTE-01**: Обычное текстовое сообщение в личном чате сохраняется без
  изменения текста, включая переносы, emoji и ссылки; страницы по ссылкам
  не загружаются.
- [ ] **NOTE-02**: После успешного сохранения пользователь получает ID заметки.
- [ ] **NOTE-03**: Сохранённые заметки доступны после повторного открытия
  файловой SQLite-БД и повторной инициализации хранилища.
- [ ] **LIST-01**: `/list` показывает последние 10 собственных заметок
  от новых к старым по `id DESC`.

### Поиск и удаление

- [ ] **SEARCH-01**: `/search <query>` ищет буквальную подстроку без учёта
  регистра, включая кириллицу и буквальные `%` и `_`, только в своих заметках.
- [ ] **SEARCH-02**: Результаты поиска выдаются от новых к старым по `id DESC`
  без отдельного лимита количества результатов.
- [ ] **DELETE-01**: `/delete <id>` удаляет собственную заметку по положительному
  целочисленному ID и подтверждает удаление после успешной операции.
- [ ] **DELETE-02**: Для чужой и отсутствующей заметки возвращается одинаковый
  ответ: «Заметка не найдена».

### Telegram-интерфейс

- [ ] **CHAT-01**: `/start` возвращает приветствие и инструкцию по командам.
- [ ] **CHAT-02**: В группах бот не сохраняет, не выдаёт и не удаляет заметки,
  а предлагает открыть личный чат.
- [ ] **INPUT-01**: Пустой или состоящий из пробелов текст и неизвестные команды
  не сохраняются; пользователь получает подсказку.
- [ ] **INPUT-02**: Пустые аргументы команд, неверный ID и неподдерживаемые
  сообщения сопровождаются подсказкой.
- [ ] **REPLY-01**: Ответы отправляются обычным текстом без HTML/Markdown.
- [ ] **REPLY-02**: Длинные ответы делятся на сообщения с соблюдением
  ограничений Telegram, в том числе для emoji.

### Изоляция и ошибки

- [ ] **SAFE-01**: Владелец определяется по Telegram `from_user.id`, а не по
  аргументам; чтение, поиск и удаление ограничены его `user_id`.
- [ ] **SAFE-02**: При ошибке хранения бот не сообщает об успешном сохранении
  или удалении.
- [ ] **SAFE-03**: Токен и тексты заметок не записываются в логи.

### Запуск и настройки

- [ ] **RUN-01**: Точка входа связывает настройки, подготовку БД и обработчики
  и запускает polling.
- [ ] **CONFIG-01**: Настройки читаются из окружения: непустой `BOT_TOKEN`
  обязателен, `DATABASE_PATH` по умолчанию — `data/notes.sqlite3`; пустой путь
  отклоняется, `.env` автоматически не загружается.

## Implementation Constraints

Ограничения из [MVP](../docs/mvp.md), [архитектуры](../docs/architecture.md)
и [плана хранения](../docs/plan.md) обязательны при планировании:

- Python 3.12+, aiogram 3, стандартный `sqlite3`, pytest, uv и Ruff.
- `storage.py` не зависит от Telegram; `handlers.py` отвечает за команды
  и ответы; `__main__.py` связывает компоненты.
- Таблица `notes`: `id INTEGER PRIMARY KEY`, `user_id INTEGER NOT NULL`,
  `text TEXT NOT NULL`, `created_at TEXT NOT NULL` в UTC. SQL — с параметрами.
- Синхронное хранилище вызывается из обработчиков через `asyncio.to_thread`;
  соединение создаётся и закрывается внутри каждой операции в рабочем потоке,
  при успехе и ошибке. Запись фиксируется до возврата успешного результата.
- Поиск получает собственные заметки и сравнивает `query.casefold()`
  с `text.casefold()`; подходит для небольшой личной базы.
- Тесты используют вымышленные данные и временную файловую SQLite-БД;
  обработчики проверяются без настоящего Telegram API.
- Git-операции, установка зависимостей, сетевой запуск и обязательные проверки
  выполняются по [правилам проекта](../AGENTS.md).

## Out of Scope

| Feature | Reason |
|---------|--------|
| LLM | Первый этап не использует LLM |
| Извлечение содержимого ссылок | Ссылки хранятся как исходный текст |
| Теги и редактирование | Исключены из согласованного MVP |
| Пагинация | MVP использует последние 10 заметок и полный результат поиска |
| Веб-интерфейс | Интерфейс MVP — Telegram |
| Работа с заметками в группах | Поддерживаются только личные чаты |
