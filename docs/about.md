# О проекте NotesBot

NotesBot — Telegram-бот для личных текстовых заметок. Цель MVP — сохранять
сообщения пользователя, показывать последние заметки, искать по тексту и удалять
записи. Работа с ботом предусмотрена в личном чате; каждый пользователь получает
доступ только к своим заметкам.

## Возможности MVP

- Сохранение обычного текстового сообщения с возвратом ID заметки.
- `/start` — инструкция по работе с ботом.
- `/list` — последние 10 собственных заметок, от новых к старым.
- `/search <query>` — поиск буквальной подстроки без учёта регистра, включая кириллицу.
- `/delete <id>` — удаление собственной заметки.

Текст сохраняется без изменений, включая переносы строк и emoji. Ссылки хранятся
как текст. В MVP не входят LLM, теги, редактирование заметок и веб-интерфейс.

## Стек

| Технология | Назначение |
|---|---|
| Python 3.12+ | Язык приложения |
| aiogram 3 | Telegram-обработчики и получение обновлений через polling |
| SQLite и стандартный `sqlite3` | Хранение заметок в локальном файле |
| `asyncio.to_thread` | Выполнение синхронных операций SQLite без блокировки event loop |
| pytest | Автоматические тесты |
| Ruff | Линтер, форматирование и проверка импортов |
| uv | Управление окружением, зависимостями и сборкой |
| uv_build | Сборка Python-пакета |

Зависимости и настройки инструментов определены в [pyproject.toml](../pyproject.toml).

## Устройство приложения

Целевая структура разделяет Telegram-интерфейс и хранение данных:

- `config.py` читает и проверяет настройки из переменных окружения.
- `storage.py` выполняет операции с SQLite независимо от Telegram.
- `handlers.py` обрабатывает сообщения и команды, обращаясь к хранилищу через
  `asyncio.to_thread`.
- `__main__.py` связывает компоненты, подготавливает БД и запускает polling.

Заметка содержит ID, ID владельца, исходный текст и время создания в UTC.
Операции с данными ограничены владельцем, SQL-запросы используют параметры.
Настройки приложения — `BOT_TOKEN` и `DATABASE_PATH`.
